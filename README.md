Replaced PureCSS with Bootstrap. Replaced login and Todo page with JSX remake. Replaced modal with in-place editing (reuses submit form rather than modal).

Using React definately had both some upsides and downsides. While it did improved writing interactive parts of the website and allowed for a more structured/modular approach it made it harder to write as it required passing alot of variables/props and split logic among many different parts. I wouldn't nessasrily consider this a negative thing as keeping everything together is not necessarily the best choice but especially when split across many files, it added extra complexity that otherwise wouldn't exist. This may be influenced by the fact it was my first time writing React so these issues may smooth out in the future. It's difficult to put into words the exact benefits that React provided as the way the interface was built was different than I would have chosen for pure Javascript, but it felt like changing elements on the page was far more reliable and less likely to cause many state issues.
